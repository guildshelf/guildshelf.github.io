Shipped this week. SkillLock — a lockfile for your installed skills: pins every file to a SHA-256 and tells you exactly what changed before it reaches your agent’s context, exit code 1 on drift so it gates a run. Skill Eval Harness — measures whether a skill fires when it should and stays quiet when it shouldn’t, then renders a scorecard with the failures included. Approval Gate — puts a human yes between what an agent extracted and what reaches your CRM or database, on an append-only audit trail; export emits approved records only, with no bypass flag. Watchdog Kit + Notify Hub — an ops pair: the watchdog restarts a job when it crashes and when it is alive but stuck (stale heartbeat), then the hub delivers the alert to whichever channel you actually read, with dedup and rate limiting so a failure loop cannot become two hundred pages. We ran all of these against our own library first; the eval harness found two bugs in itself doing it, and every shipped skill now lints clean.
